# 首页主题切换修复

实际点击主题按钮复现：页面已经进入 default 浅色模式，但专题卡、精选笔记配图、导航和页脚仍使用固定深色。

修复范围：

- 专题卡、底栏、配图区域和首页导航 / 页脚使用现有主题变量。
- 六个 SVG 图形的背景、线条和文字使用主题变量；构建时将首页配图内联，让手动主题选择即时作用于图形。
- 白色 SVG 图标保留，使用小面积深色底保证对比。
- 页脚文字与社交链接使用对应主题的前景颜色。

验证：

- 在 1440、1024、768、390px 下实际点击浅色、深色、浅色，共 12 个切换状态通过。
- 在系统深色时手动选择浅色并刷新，选择仍被保留。
- 选择自动模式后，修改系统颜色偏好，页面继续跟随系统。
- 浏览器检查专题、SVG 背景与文字、导航、页脚、白色主题图标和页面溢出。
- MkDocs 构建与 SVG XML 校验成功；JavaScript 语法检查成功。

本地回归检查：`node tests/home-theme.cjs`。测试文件遵循仓库原有 Git 忽略规则。

截图：`previews/light-before-theme-fix.png` 为修复前；`previews/desktop.png`、`previews/mobile.png`、`previews/dark.png` 为修复后。
