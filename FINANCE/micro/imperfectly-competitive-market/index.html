    不完全竞争市场

    约 2532 个字 75 张图片 预计阅读时间 8 分钟

    完全垄断市场 Monopoly Market¶

    完全垄断市场的特征与成因¶

    完全垄断的收益¶

    厂商的需求曲线 = 市场需求曲线，斜向下：随价格增加，需求量减少

    \(MR \lt P\)

    根据 P 求 MR：

    \(P = a - bQ，TR = P*Q = aQ - bQ^2， MR = d(TR)/dQ = a - 2bQ\)

    完全垄断的均衡¶

    短期均衡¶

    利润情况：

    读图方法：

    由 \(MR = MC\) 求出均衡产量 \(Q^*\)，再由需求曲线（\(D(AC)\)）求出均衡价格 \(P^*\)，再由 \(SAC\) 曲线找到 \(Q^*\) 对应的单位成本 \(SAC^*\)，利润为 \((P^* - SAC^*) * Q^*\)。

    长期均衡¶

    长期均衡中垄断不可能有负利润。但是可能有正利润（因为其他企业进入受限）。

    长期，可以通过调整生产规模来调整利润。

    垄断者没有供给曲线

    怎么理解没有供给曲线

    垄断的经济效率¶

    剩余分析：

    存在无谓损失

    社会总剩余（Total Surplus, TS）通常被用作衡量社会福利（Social Welfare）或经济福利（Economic Well-being）的指标。

    经济租：在完全竞争市场中生产者剩余为零（见上上图黄线），而在垄断市场中，生产者剩余为正，这部分超额收益被称为经济租（Economic Rent）。

    经济租就是垄断让生产者剩余变大了的那部分。

    寻租行为（Rent-seeking Behavior）：指个体或企业通过非生产性手段（如游说、垄断权利获取等）来获取经济租的行为。这种行为通常会导致资源的浪费和社会福利的损失。寻租行为最大愿意投入的成本就是经济租。

    价格歧视理论¶

    概念¶

    Theory of Price Discrimination

    条件¶

    市场势力：

    • 能够影响价格，而非被动接受市场价格的能力

    分割：

    • 防止消费者套利（转售）
    • 人群可以被有效区分

    （3）：price discrimination could increase social welfare if it enables more consumers to be served.

    是“可能可以 could”

    原因¶

    类型¶

    一级价格歧视¶

    perfect Price Discrimination / First-Degree Price Discrimination

    每一单位产品都像消费者索取其愿意支付的最高价格

    一级价格歧视卖到P = MC为止，产量等于完全竞争市场的时候

    原因

    消费者剩余为0，社会上有剩余都在垄断者那里。且不产生无谓损失/福利损失。

    商家通过大数据等手段，了解每个消费者的支付意愿，从而进行个性化定价。

    二级价格歧视¶

    versioning / Second-Degree Price Discrimination

    核心：商家给消费者提供一个 menu，让消费者 自我选择

    例子：

    • 第二杯半价
    • 精装/平装版书
    • 头等舱/经济舱：商家想让高支付意愿的消费者选择头等舱，低支付意愿的选择经济舱（通过设计不同的体验，经济舱不能设计的太舒服）
    • 视频平台会员
    • 护肤品保湿补水的比抗老的便宜

    消费者剩余被部分挤出

    一个例子：

    一般来说，厂家会将低支付意愿的消费者的消费者剩余全部拿走，而高支付意愿的消费者会剩下一部分消费者剩余。

    三级价格歧视¶

    market segmentation / Third-Degree Price Discrimination

    厂家划分的市场/消费者

    计算：

    即要求两个市场的边际收入相等且等于边际成本

    为什么 MR1 = MR2 = MC
    1. 如果 MR1 > MR2，则可以通过增加市场 1 的产量并减少市场 2 的产量来增加总利润，反之亦然。因此，利润最大化的条件是 MR1 = MR2。
    2. 同时，为了实现利润最大化，边际收入必须等于边际成本（MC）。如果 MR 大于 MC，企业可以通过增加产量来增加利润，反之亦然。因此，利润最大化的条件还包括 MR = MC。

    将消费者分成 \(n\) 个市场，利润最大化条件：\(MR_1 = MR_2 = ... = MR_n = MC\)

    被分割的每个市场都是一个完全垄断市场

    \(\epsilon\) 是负数，他越大，弹性越小（绝对值越小）

    需求弹性越小的市场，价格越高：对价格不敏感就收高价，很合理

    MR 与弹性的公式

    推导：算 MR，把 P 提出来，熟悉弹性公式

    \(TR = P * Q\)

    \(MR = d(TR)/dQ = d(P*Q)/dQ = P + Q * dP/dQ\)

    由弹性定义：\(E = (dQ/dP) * (P/Q)\)，则 \(dP/dQ = 1 / (dQ/dP) = P / (E * Q)\)

    代入 MR 公式：

    \(MR = P + Q * (P / (E * Q)) = P + P / E = P(1 + 1/E)\)

    寡头垄断市场 Oligopoly Market¶

    特征&成因¶

    成因：

    卡特尔¶

    可以将其视作一个完全垄断市场

    就是博弈论中经典的：囚徒困境

    所以寡头的产量/价格是在完全垄断和完全竞争之间的

    寡头垄断模型¶

    Cournot Model 和 Stackelberg Model 都是产量竞争（寡头决定产量，市场决定价格），Bertrand Model 是价格竞争（寡头决定价格，市场决定产量）。

    要求

    1. 知道什么情况下用哪个模型
    2. Cournot 和 Stackelberg 要会计算
    3. Bertrand 和 Sweezy 要知道结论

    古尔诺模型 Cournot Model¶

    特征

    “两个同样水平的厂商同时决定产量”

    成本为零不是古尔诺模型的基础假设，只是基础课里面为了简化计算。

    A 和 B 同时做决定，A 在做决策时觉得 B 的产量不变。不能观测到对方的决策。A 在做决策时推测 B 的产量是多少，按照这个产量来决定自己利润最大的产量。

    计算方法：

    1. 写出总需求函数 \(P = H - aQ\)，其中 \(Q = Q_A + Q_B\)。
    2. 写出 A 和 B 的收益函数 \(\Pi_A = P * Q_A\)，\(\Pi_B = P * Q_B\)。
    3. 对 A 求 \(\Pi_A\) 关于 \(Q_A\) 的一阶导数，令其等于 0，解出 A 的反应函数 \(Q_A^* = \frac{H - aQ_B}{2a}\)。B 同理，解出 B 的反应函数 \(Q_B^* = \frac{H - aQ_A}{2a}\)。

    4. 联立 A 和 B 的反应函数，解出均衡产量 \(Q_A^*\) 和 \(Q_B^*\)。

      • 反应函数：做出 best response 的函数。即给定 H 和 \(Q_B\)，A 根据这个函数求出的最优产量是多少。
      • 这里可以联立的原因：A的反应函数里面 \(Q_B\) 是 A 认为 B 的产量，当 B 实际的产量等于 A 认为的产量时，就不再发生变化。 5. 将均衡产量代入总需求函数，解出均衡价格 \(P^*\)。

    斯坦克贝模型 Stackelberg Model¶

    特征

    “两个厂商先后决定产量”

    博弈论/经济学中先和行动问题的一般思路

    从最后一步往前推，即先考虑后行动的一方

    计算方法：

    1. 写出总需求函数 \(P = H - aQ\)，其中 \(Q = Q_A + Q_B\)。
    2. 写出后发者（假设是 B）的收益函数 \(\Pi_B = P * Q_B = (H - aQ_A)Q_B - aQ_B^2\) 。
    3. 对 B 求 \(\Pi_B\) 关于 \(Q_B\) 的一阶导数，令其等于 0，解出 B 的反应函数 \(Q_B^* = \frac{H - aQ_A}{2a}\)。

    4. 列出先发者的收益函数 \(\Pi_A = P * Q_A = (H - a(Q_A + Q_B^*))Q_A\)，将 B 的反应函数代入。

      • 不能直接用 A 的收益函数对 \(Q_A\) 求导，因为 B 会根据 A 的产量来调整自己的产量，即 \(Q_B\) 是变量。 5. 对 A 求 \(\Pi_A\) 关于 \(Q_A\) 的一阶导数，令其等于 0，解出均衡产量 \(Q_A^*\)。 6. 将 \(Q_A^*\) 代入 B 的反应函数，解出均衡产量 \(Q_B^*\)。 7. 将均衡产量代入总需求函数，解出均衡价格 \(P^*\)。

    领导者利润占优（先发着优势）

    贝尔兰特模型 Bertrand Model¶

    特征

    “两个同样水平的厂商同时决定价格”

    特征：

    1. 寡头之间通过定价竞争
    2. 考虑到竞争对手的价格后选择其价格
    3. 实现自身利润最大化

    假设：

    1. 产品同质
    2. 单位成本固定，即不存在边际成本递增

    定价低的占领整个市场，定价高的没有市场，定价一样平分市场

    结论：

    均衡价格 = 边际成本，仅存在唯一的纳什均衡（唯一价格）

    给定 A 的价格不变，B 降价会占领整个市场但是利润为负（\(\pi_B = (P_B - MC) \cdot Q_{Total} < 0\)）；B 提价会失去整个市场于是销量为零利润为零（\(\pi_B = (P_B - MC) \cdot 0 = 0\)）；所以 B 没有改变价格的动机。A 同理。

    解释

    双寡头贝尔兰特模型的均衡条件和完全竞争市场相同：Bertrand Paradox

    引入差别，消费者偏好后，均衡价格会高于边际成本，经济利润提高

    其他解决方案：引入生产规模/生产能力限制

    或者引入无限期/不确定期限合作（抬高价格）。

    • 如果合作期限确定，用 backward，最后一期肯定有一方降价，倒数第二期也是，依次类推，不可能在确定期限内合作成功。

    斯威齐模型 Sweezy Model¶

    用于解释价格刚性。

    价格刚性（Price Rigidity）：指在某些市场条件下（例如 MC 提高），价格对供需变化表现出较强的抵抗力，即价格在短期内难以发生显著变化的现象。

    假设的核心：寡头厂商之间非对称反应（Asymmetric Response）

    解释方法

    其他解释价格刚性的理论：

    • menu cost 菜单成本：改变价格产生的成本，例如修改菜单重新标价、和顾客沟通等。

    寡头垄断厂商的勾结与定价策略¶

    • 晴雨表型：消息最多的定价

    成本加成：成本 + 固定百分比，需求价格弹性越大，成本加成越小，因为需求弹性大，消费者对价格敏感，成本加成过高会导致销量大幅下降。

    垄断竞争市场 Monopolistic Competition Market¶

    特征：

    产品的差异性带来垄断力量，产品差异性越大，垄断力量越大

    因为进出自由，长期均衡时利润为零

    需求曲线¶

    • 有替代性，则消费者价格敏感度更高，需求曲线比完全垄断市场更平坦
    • MR 曲线同样在需求曲线下方。因为只要 P 和 Q 成反方向变化，MR 就小于 P

    主观：忽略别人，只考虑自己抬价/降价。

    如果只有一家降价/抬价（主观），消费者敏感度高，需求量变化大，需求曲线更平
