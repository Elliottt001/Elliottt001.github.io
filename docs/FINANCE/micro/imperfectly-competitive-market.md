> 社会总剩余（Total Surplus, TS）通常被用作衡量社会福利（Social Welfare）或经济福利（Economic Well-being）的指标。

经济租：在完全竞争市场中生产者剩余为零（见上上图黄线），而在垄断市场中，生产者剩余为正，这部分超额收益被称为经济租（Economic Rent）。

经济租就是垄断让生产者剩余变大了的那部分。

寻租行为（Rent-seeking Behavior）：指个体或企业通过非生产性手段（如游说、垄断权利获取等）来获取经济租的行为。这种行为通常会导致资源的浪费和社会福利的损失。寻租行为最大愿意投入的成本就是经济租。

???+ question "为什么 MR1 = MR2 = MC"

    1. 如果 MR1 > MR2，则可以通过增加市场 1 的产量并减少市场 2 的产量来增加总利润，反之亦然。因此，利润最大化的条件是 MR1 = MR2。
    2. 同时，为了实现利润最大化，边际收入必须等于边际成本（MC）。如果 MR 大于 MC，企业可以通过增加产量来增加利润，反之亦然。因此，利润最大化的条件还包括 MR = MC。

将消费者分成 $n$ 个市场，利润最大化条件：$MR_1 = MR_2 = ... = MR_n = MC$

![alt text](res/images/image-84.png)

被分割的每个市场都是一个完全垄断市场

![alt text](res/images/image-85.png)

$\epsilon$ 是负数，他越大，弹性越小（绝对值越小）

需求弹性越小的市场，价格越高：对价格不敏感就收高价，很合理

!!! info "MR 与弹性的公式"

    推导：算 MR，把 P 提出来，熟悉弹性公式

    $TR = P * Q$

    $MR = d(TR)/dQ = d(P*Q)/dQ = P + Q * dP/dQ$

    由弹性定义：$E = (dQ/dP) * (P/Q)$，则 $dP/dQ = 1 / (dQ/dP) = P / (E * Q)$

    代入 MR 公式：

    $MR = P + Q * (P / (E * Q)) = P + P / E = P(1 + 1/E)$
