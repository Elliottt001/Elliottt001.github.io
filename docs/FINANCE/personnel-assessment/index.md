# 人事测评与选拔

这门课讨论怎样了解一个人的能力、判断人与岗位或组织是否匹配，以及如何设计可信的选拔工具。笔记按15次课分别整理，侧重知识与理论，保留帮助理解的课堂案例。

每个知识点先给出 **AI讲解**，说明概念、机制和适用条件；随后是 **老师上课讲解**，按清洗字幕节选原话，并保留时间定位。

## 内容脉络

- **课程背景与匹配框架（1—4节）**：人才测评为什么产生、选拔流程如何形成，以及人岗匹配、人与组织匹配的区别。
- **测量基础与人员信息（5—8节）**：信度、效度、工作分析、胜任力建模、履历数据和背景调查。
- **具体选拔方法（9—13节）**：笔试、结构化面试、案例面试、无领导小组讨论和公文筐。
- **组合与评价（14—15节）**：怎样综合多种方法、解释分数，以及识别算法偏见。
