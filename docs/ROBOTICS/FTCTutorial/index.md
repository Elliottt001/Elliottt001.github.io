## 调试时的检查顺序

1. **硬件映射**：检查配置名称、接线和方向是否与代码一致。
2. **单个设备**：先确认一个电机、伺服或传感器的输入输出，再组合动作。
3. **遥测输出**：显示手柄值、位置、角度和当前状态，观察实际变化。
4. **操作模式生命周期**：确认初始化、等待开始、循环与停止发生在正确阶段。
5. **控制与路径**：基础输入输出正确后，再排查 PID、坐标、路径和状态切换。

这些是学习与项目记录，具体接口、硬件方向和场地坐标应以使用的 SDK、机器人配置和对应赛季为准。
