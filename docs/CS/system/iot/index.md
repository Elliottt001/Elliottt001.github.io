## 阅读方式

**知识点**整理核心概念、公式、适用条件和比较关系；**老师讲解**引用课堂字幕，注明课次和时间，保留有意义的解释、问答和例子。架构、协议时序与开发流程等内容适量配有 PPT 原图，点击图片可放大。

图片和知识点引用的页码均指 PDF 物理页，可能与课件页脚编号不同。历史数据、性能结果及实验条件按对应课堂或课件的语境理解。

## 材料覆盖

第一、二、三章的部分内容跨课堂讲授，已按知识点合并。第五章将短距离和长距离通信放在同一章。

第四、八章没有完整对应课堂字幕，知识点主要依据 PPT，讲解仅引用其他课次的相关原句；没有讲解的部分会注明。其他章节中 PPT 保留但课堂未展开的内容，也与实际讲解分开呈现。

字幕识别不清的地方保留提示；由 PPT 补充的术语、公式或计算单独放在知识点中。有关考试形式和实验安排，以老师后续通知为准。
