关系型数据库：数据放在表里，一行是一条记录，一列是一种属性。

比如选课：学生一张表、课程一张表、选课关系再一张表。不用把课程名复制到每个学生后面，关系里存学生 ID 和课程 ID 就行。

- 主键：认出这一行是谁，不能重复，也不能是 NULL。
- 外键：把表联系起来，例如选课表的学生 ID 指向学生表。
- SQL 写的是“要哪些数据”，具体怎么查由数据库去安排。
