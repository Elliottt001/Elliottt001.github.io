## SQL

??? waring "聚合函数不能出现在 `WHERE` 后面，应该在 `HAVING` 后面"

    在中文里：

    1. “把**薪水大于1万**的人选出来” $\rightarrow$ 这个“的”，主语是**单个人**（个体属性）。
    2. “把**总人数大于5**的部门选出来” $\rightarrow$ 这个“的”，主语是**一群人**（集体属性）。

    人类觉得这两个“的”一样，但 SQL 不是。

    SQL 的工作流水线：写 SQL，顺序是：`SELECT -> FROM -> WHERE -> GROUP BY -> HAVING`。但数据库执行 SQL 时，它的阅读顺序是完全颠倒的：

    1. **`FROM`**（把存数据的档案柜搬过来）
    2. **`WHERE`**（**安检员**：挨个检查**单张**个人简历）
    3. **`GROUP BY`**（**带队长**：把通过安检的人，按部门**分出小组**）
    4. **`HAVING`**（**裁判长**：审视**分组后**的整体数据）
    5. **`SELECT`**（把最终留下的数据写在报告上）

    把你的大脑字典升级一下，**把中文里的“的”，强行拆成两个词**：

    * 凡是能塞进 **“XXX（单个人）的...”** 句式的 $\rightarrow$ 归给 **`WHERE`**
    *(例如：张三**的**工资、李四**的**性别、王五**的**入职时间)*
    * 凡是必须塞进 **“XXX们（这帮人）的...”** 句式的 $\rightarrow$ 归给 **`HAVING`**
    *(例如：开发部们**的**总人数、销售部们**的**平均业绩、男女生们**的**最高薪资)*
