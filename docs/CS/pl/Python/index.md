## 常用工具

### IPython

```shell
python3 -m IPython     # 启动
exit                   # 或 exit() 退出
```

查看帮助：

```shell
help()
# 输入 modules / keywords / symbols / topics 列出条目
# q 退出某个条目，quit 退出 help
```
